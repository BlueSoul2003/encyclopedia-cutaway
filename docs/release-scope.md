# Release scope

This repository is a reusable skill and a collection of generated concept illustrations, not a mirror of a personal workspace. Its canonical skill lives in `.agents/skills/encyclopedia-cutaway`.

Include the skill, a generated style reference, deliberately selected generated examples, their actual prompts, primary-source links, installation instructions, and a lightweight package validator. Exclude user-uploaded reference images, account credentials, private workspace paths, transient renders, and unrelated project material.

The public package uses an English skill entrypoint so people can request output in their own language. Language, background, density, and incidental living scenes remain configurable. The multilingual examples demonstrate observed results, not a guarantee of native-language proofreading or deterministic generation.

Repository instructions and selected generated examples use MIT, matching the author's existing reusable-skill projects. Third-party technical sources remain external links, with no rights claimed over their content. Original private experiments stay outside this repository.

Before publishing, validate the exact package and inspect the selected images. The user has explicitly requested public GitHub sharing. Publish from this isolated repository only; no other project is included.
